# Separate private working memory from shared organizational memory

Each Agent owns Private Memory for continuity, while Teams use Shared Memory explicitly scoped to a
Workspace, Project, Mission, or Team. Knowledge crosses that boundary only through Memory Promotion,
which creates a new provenance-linked record without changing or erasing its source.

## Consequences

Other Agents cannot read Private Memory by default. The Operator may inspect it, but every access
is deliberate, attributable, and recorded in Activity. Raw Trace is not automatically Memory.
Retention, summarization, promotion, and deletion are separate policy decisions. Closing a
Specialist archives its private working memory under Policy, promotes necessary handoff knowledge
explicitly, and preserves attributable Artifacts and Receipts.
