# Combine bounded autonomy with human authority

Beacon automatically enforces reversible work that fits an operator-authored Policy and sends
exceptions or high-risk effects to an operator Gate. Every external effect passes through
Execution as an immutable Proposal bound to its policy, base revision, targets, sandbox, checks,
and budget. This keeps routine agent work fluid without turning autonomous Team formation,
Specialist creation, a model judgment, evidence record, desktop button, or prior Ruling into
ambient permission.

## Consequences

Projects choose Observe, Supervised, or Bounded autonomy and default to Supervised in Alpha 1.
Resource authority nests as hard Workspace, Project, Mission, and Agent Budget Envelopes. A child
cannot exceed, borrow from, transfer, or enlarge its parent's ceiling.

Before first enabling Bounded autonomy in a Workspace, the Operator acknowledges a concise safety
notice covering possible external effects, the limits of Policy, Pause Work, and Receipt review.
The acknowledgement is educational: it grants no authority, waives no rights, and replaces no
Gate.

Production, public, destructive, security-sensitive, financial, legal, credential-expanding, and
unprovable effects always gate. Material Proposal drift invalidates a Ruling. A denied Proposal
must cause no external mutation, and every dispatched Run must emit a Receipt.
