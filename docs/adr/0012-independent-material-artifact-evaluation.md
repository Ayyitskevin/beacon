# Separate Material Artifact authorship from evaluation

A Material Artifact must be evaluated by an Agent other than its author before it can support a
Ruling, authorize effects, claim Mission success, or become a durable shared deliverable. This
preserves an independent judgment boundary without making an evaluator an authority holder.

## Consequences

The Evaluation records both identities, criteria, inputs, findings, uncertainty, and conflicts.
Deterministic checks supplement rather than replace independent evaluation. An evaluator can reject
or request revision but cannot authorize execution.
